OBJECT (OBJEK)

DALAM KALIMAT BAHASA INGGRIS

Materi lengkap untuk memahami fungsi, pola, dan penggunaan Object dalam TOEFL Structure & Written Expression.

Skor Latihan: 0 / 25
1. APA ITU OBJECT?

Object adalah kata, kelompok kata, atau klausa yang menerima tindakan dari verb.

SUBJECT + VERB + OBJECT
The teacher explained the lesson.

The teacher = Subject
explained = Verb
the lesson = Object

Pertanyaan sederhana untuk menemukan object:

  • Verb-nya melakukan tindakan kepada siapa?
  • Verb-nya melakukan tindakan kepada apa?
She reads the book.
→ Reads what? → the book = Object
Perhatikan:
Tidak semua verb membutuhkan object.

❌ She read.
✅ She read the book.
2. BENTUK-BENTUK OBJECT

A. Noun sebagai Object

Noun adalah kata benda yang menerima tindakan.

The student bought a laptop.
The company hired new employees.

B. Pronoun sebagai Object

Subject Object
I me
you you
he him
she her
it it
we us
they them
The manager called me.
The teacher helped him.
The professor invited them.

C. Noun Phrase sebagai Object

Noun phrase adalah kelompok kata yang inti utamanya adalah noun.

They discussed the results of the study.

D. Gerund sebagai Object

Gerund adalah V-ing yang berfungsi sebagai noun.

She enjoys reading novels.
He avoids driving at night.

E. Infinitive sebagai Object

Infinitive = to + V1.

I want to improve my English.
They decided to leave early.
3. POLA PENTING SETELAH VERB

1. MAKE + OBJECT + V1

make + object + V1
She made the students complete the assignment.

Setelah make + object, gunakan V1 tanpa "to".

❌ She made him to leave.
✅ She made him leave.

2. LET + OBJECT + V1

let + object + V1
The manager let the employees leave early.

3. HAVE + OBJECT + V1

have + object + V1
The supervisor had the technician inspect the machine.

4. ASK + OBJECT + TO + V1

ask + object + to + V1
The teacher asked the students to submit their reports.

5. EXPECT + OBJECT + TO + V1

expect + object + to + V1
The company expects employees to demonstrate professional behavior.

6. ADVISE + OBJECT + TO + V1

advise + object + to + V1
The doctor advised the patient to rest.
4. PREPOSITION + V-ING

Setelah preposition, bentuk verb yang digunakan sebagai object adalah V-ing / gerund.

PREPOSITION + V-ING

Preposition yang sering muncul:

Preposition Contoh
about talking about
after after finishing
before before leaving
by by studying
for for helping
from from working
in in learning
of of studying
on on improving
with with solving
He is interested in learning English.
❌ interested in learn
❌ interested in to learn
✅ interested in learning
5. JEBakan TOEFL YANG SERING MUNCUL

A. Dummy "It"

Dalam pola tertentu, it bukan object. It dapat berfungsi sebagai dummy subject.

I found it difficult to understand the problem.

Pola:

find + it + adjective + to + V1

B. Object Complement

Object dapat diikuti complement yang menjelaskan object tersebut.

They considered the proposal to be an effective solution.

C. Noun Clause sebagai Object

Noun clause dapat berfungsi sebagai object.

I believe that he will succeed.

D. Parallel Structure

The students not only completed the project but also presented their findings.
Setelah not only ... but also, bentuk yang disejajarkan harus sama.
