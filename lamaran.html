Cara Mendapatkan Gemini API Key

Gunakan Google AI Studio untuk membuat API key Gemini.

  1. Buka Google AI Studio dan login dengan akun Google.
  2. Klik Create API key.
  3. Pilih project Google Cloud atau buat project baru.
  4. Salin API key yang dibuat.
  5. Tempelkan key ke kolom Gemini API Key di halaman ini.

Jangan membagikan API key kepada orang lain atau memasukkannya ke kode publik.

Key disimpan hanya di browser ini dan dikirim ke endpoint Gemini saat fitur AI digunakan.
