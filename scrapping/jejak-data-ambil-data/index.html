Jejak Data: Kaggle & Web Scraping untuk Pemula

Panduan langsung, skrip siap pakai Python di Windows, dan prinsip etika data digital.

📁 Paket Latihan Lokal: Seluruh skrip Python siap pakai telah tersedia di folder latihan/ di dalam arsip ini. Anda dapat menjalankannya di Command Prompt Windows setelah memasang dependensi dari requirements.txt.

Modul 1: Peta Data — Dari Mana Data Berasal

Bandingkan 3 jalur perolehan data: Kaggle (dataset siap pakai), API Resmi (terstruktur & legal), dan Web Scraping (pilihan terakhir). Utamakan selalu Kaggle & API resmi sebelum scraping.

Hierarki Rekayasa: Dataset Kaggle → API Resmi → Web Scraping Mandiri

Modul 2: Kaggle Langkah demi Langkah & Pandas

Membuat akun di kaggle.com, mengunduh token kaggle.json dan meletakkannya di C:\Users\<Nama>\.kaggle\kaggle.json. Membuka file CSV dengan Pandas menggunakan df.head(), df.info(), dan df.describe().

import kagglehub path = kagglehub.dataset_download("zynicide/wine-reviews") import pandas as pd df = pd.read_csv("contoh_buku.csv") print(df.head())

Modul 3: Dasar HTML untuk Web Scraping

Memahami struktur tag, atribut (seperti title untuk teks lengkap), class, dan id. Menggunakan Inspect Element (F12 di browser) dan merumuskan CSS selector yang tepat.

soup.select("article.product_pod h3 a") tag["title"] # Mengambil atribut judul tersembunyi

Modul 4: Scraping dengan requests & BeautifulSoup

Alur kerja 4 langkah: Kirim HTTP GET → Periksa status_code 200 → Parsing teks dengan BeautifulSoup → Simpan data ke CSV. Berjalan terhadap situs latihan legal: books.toscrape.com dan quotes.toscrape.com.

response = requests.get(url, headers={"User-Agent": "LatihanPemula/1.0"}) soup = BeautifulSoup(response.text, "html.parser")

Modul 5: Kasus Sulit, Pagination & Status Codes

Scraping multi-halaman dengan time.sleep(2), memahami keterbatasan requests pada situs berbasis JavaScript (SPA/React), serta penanganan status code 200, 404, 403 (Forbidden), dan 429 (Too Many Requests).

if response.status_code == 404: break # Batas akhir pagination time.sleep(2) # Santun kepada server target

Modul 6: Etika, robots.txt & UU PDP di Indonesia

Membaca aturan robots.txt, Terms of Service, prinsip UU Perlindungan Data Pribadi No. 27/2022 (larangan mengumpulkan data pribadi sensitif), dan prinsip sopan santun digital.

User-agent: * Disallow: /admin/ Crawl-delay: 3

Langkah Menjalankan Kode di Komputer Windows

  1. Pasang Python: Unduh dari python.org/downloads. Saat menginstal, CENTANG: "Add python.exe to PATH".
  2. Buka Terminal: Tekan Win + R, ketik cmd, tekan Enter.
  3. Masuk ke Folder Latihan: Masuk ke folder skrip dengan perintah:
    cd latihan
  4. Pasang Library yang Dibutuhkan:
    pip install -r requirements.txt
  5. Jalankan Skrip:
    python 01_baca_csv.py python 03_scrape_satu_halaman.py python 05_simpan_ke_csv.py

Solusi Masalah Umum di Windows

Pesan: 'python' is not recognized: Centang opsi PATH belum aktif. Jalankan ulang installer Python dan pilih Modify → Add Python to environment variables.

Pesan: 403 Forbidden: Tambahkan header User-Agent yang ramah pada pemanggilan requests.get().

Pesan: UnicodeDecodeError: Gunakan pd.read_csv("file.csv", encoding="utf-8") atau encoding="latin1".

5 Skrip Python Bertingkat di Folder latihan/

  • 01_baca_csv.py: Membaca file CSV dengan pandas, mengecek head(), info(), dan describe().
  • 02_kaggle_api.py: Mengunduh dataset via Kagglehub atau Kaggle CLI dengan verifikasi kredensial.
  • 03_scrape_satu_halaman.py: Mengambil kutipan dari quotes.toscrape.com satu halaman dengan requests + BeautifulSoup.
  • 04_scrape_banyak_halaman.py: Scraping 3 halaman pagination dengan loop, URL format, dan delay time.sleep(2).
  • 05_simpan_ke_csv.py: Mengambil judul, harga, dan rating buku lalu menyimpannya ke hasil_scrape_buku.csv.

Checklist Sopan Santun Praktisi Data

1. Apakah data memuat data pribadi sensitif (KTP, nomor HP, email pribadi, rekam medis)? DILARANG KERAS.

2. Apakah jalur URL dilarang dalam file robots.txt? Patuhi larangan Disallow.

3. Apakah scraper Anda menyertakan jeda waktu (time.sleep)? Wajib minimal 1-2 detik.

4. Apakah situs sudah menyediakan API resmi atau dataset Kaggle? Utamakan API resmi.
