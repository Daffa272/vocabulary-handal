Analisis FGD Pribadi

Analisis kasus, evaluasi strategi, simulasi argumen, dan penyusunan draf opini untuk membantu Anda menghadapi Focus Group Discussion.

Pengaturan Gemini

Pilih bahasa untuk seluruh hasil analisis dan jawaban lanjutan. Bahasa kasus dan masukan peserta boleh berbeda; nama, akronim, dan istilah teknis tetap dipertahankan.

API key disimpan hanya di browser ini menggunakan localStorage dan dikirim langsung ke Google Gemini. Jangan memasukkan API key ke repository GitHub publik.

Catatan keamanan: untuk aplikasi pribadi, model ini dapat menggunakan API key pengguna. Untuk website publik dengan satu API key milik Anda, gunakan backend/serverless function agar key tidak terekspos di browser.

Motivasi

Isi motivasi Anda di sini. Catatan ini akan disimpan di browser Anda dan dapat membantu personalisasi analisis saat Anda menggunakan alat ini.

1. Kasus dan Tugas

Data ini akan digunakan untuk menilai kesesuaian strategi dengan arah dan nilai perusahaan. Jika dikosongkan, AI tidak akan mengasumsikan visi atau misi perusahaan.

Nama produk dan wilayah ekspor hanya disimpan di browser ini dan tidak dikirim ke AI.

2. Pendapat Peserta Lain

Masukkan pendapat peserta jika sudah tersedia. AI akan mengidentifikasi titik sepakat, perbedaan, kekuatan argumen, dan celah logikanya.

3. Analisis

Analisis AI bersifat sebagai alat bantu. Validasi kembali fakta, angka, dan asumsi sebelum digunakan dalam FGD.
