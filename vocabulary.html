Cara Mendapatkan Kunci API Gemini

Anda memerlukan Kunci API dari Google AI Studio agar aplikasi ini dapat berfungsi. Prosesnya gratis dan cepat.

  1. Buka Google AI Studio dan login dengan akun Google Anda.
  2. Klik tombol Create API key.
  3. Klik Select a Cloud Project, lalu buat project dan isi nama project Anda.
  4. Pilih project yang telah dibuat, lalu isi nama kunci API Anda.
  5. Kunci API baru akan dibuat. Klik ikon salin di sebelahnya untuk menyalin kunci tersebut.
  6. Tempel kunci yang sudah disalin ke kolom API Key di atas agar dapat digunakan aplikasi.
